# Dockerized 3-Tier Fitness Application

## Project Overview

This project demonstrates how to build, containerize, deploy, and automate a production-style three-tier fitness application using modern DevOps practices.

The goal is to simulate a real-world enterprise deployment while following industry best practices for infrastructure, automation, CI/CD, and monitoring.

---

## Tech Stack

- Docker
- Docker Compose
- MySQL
- AWS EC2
- AWS RDS
- Terraform
- GitHub Actions
- GitHub Container Registry (GHCR)
- Nginx
- CloudWatch
- Linux (Ubuntu)

---

## Project Phases

- Phase 1 – Local Development
- Phase 2 – AWS Deployment
- Phase 3 – Infrastructure as Code (Terraform)
- Phase 4 – CI/CD with GitHub Actions
- Phase 5 – Monitoring & Logging
